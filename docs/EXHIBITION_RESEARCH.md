## 確定事項 (2026-10-04)

ユーザー決定（最終）。以降の本文と食い違う場合はこの節が優先。機械可読版は `data/exhibition-profile.json`、実装仕様は `SPEC.md`。

- **範囲**: 日本全国、地域で基準を変えない。表示は upcoming（告知済み）＋ ongoing のみ。終了は非表示（データには status=ended で残し履歴・重複排除に使う）
- **更新・通知**: 毎日更新。基準を満たす新着は既存のLINE/メール通知で知らせる
- **全件収集**: NEORT++、オンチェーン、ジェネラティブアートの展覧会
- **デザイン展**: 光・空間・アーカイブ型（空間体験/思考の可視化。例 BLACK AND BLUE、田中義久 ARCHIVE/ACHIEVE）のみ。プロダクトのショールーム型は除外
- **AIアート**: メディアアート文脈（作家主導・空間的。例 真鍋大度）のみ。「AI生成画像」展は除外
- **X/Instagram**: サイトにURL投稿フォームを置き、翌日の日次ジョブが取得→公式サイトで裏取り→追加。投稿された展示は強い嗜好シグナルとしても扱う
- **除外**: 純粋な絵画/古美術/ブロックバスター巡回展、IP/キャラクター展、物販中心の大衆向け没入型エンタメ
- **ソース**: 無料のみ。日次ジョブは tech と同様に Claude CLI（WebSearch/WebFetch）
- **嗜好シグナル専用（掲載しない）**: #3 BLACK AND BLUE（2026-06-22終了）、#5 小松宏誠展（2026-09-27終了）。プロファイルの学習にのみ使う

- 光・霧・ガラス・音など「知覚/物質」を扱うインスタレーションが明確な軸（#3,4,5,6）。テクノロジーは手段であって、コード必須ではない。

- 自動スクレイピングは不安定(ログイン壁・規約)。実用手段: (1) fxtwitter API `https://api.fxtwitter.com/{user}/status/{id}` は**単発ポストの取得に有効**(本調査で成功) → ユーザーが共有したURL/ブックマークの解析用。(2) Instagram `/p/{id}/embed/captioned/` も単発取得に成功 **[F]**。(3) アカウント巡回は不可と割り切り、**ユーザーがURLを投げる受け口**(サイトのフォーム/メモ)＋その投稿から作家・会場名を抽出して各公式サイトで裏取りする方式を推奨。(4) 監視候補アカウント: @ayupys(本件)、NEORT++、真鍋大度/Rhizomatiks、exonemo、各美術館公式 — ただしタイムライン自動取得は不可 **[I]**。

## D. データ項目・スコアリング

### データ項目
`id`(source_url正規化のハッシュ), `title`, `artists[]`, `venue_name`, `venue_type`(museum/commercial_gallery/alt_space/online/popup/corporate), `prefecture`, `city`, `start_date`, `end_date`, `status`(upcoming/ongoing; 終了は自動で除外/アーカイブ), `admission`(無料/金額/UNKNOWN), `genre_tags[]`(generative, media_art, onchain, installation, light, kinetic, design, sculpture …), `scale`(S/M/L), `why_match`(1〜2文、根拠を[F]/[I]で), `score`(0-100), `source_url`, `source_name`, `image_url`, `first_seen`, `verified`(公式で裏取り済みか)

### スコアリング（100点・確定版。数値は data/exhibition-profile.json の scoring と一致）
- 技術/ジェネラティブ/メディアアート/AI(メディアアート文脈)/オンチェーンが中核: +35（周辺的なら+15）
- 光・空間・キネティック・インスタレーション: +20
- アート×デザイン×テクノロジーの境界領域: +10（デザインは光・空間・アーカイブ型のみ）
- 既知/関連作家（watch.artists）: +15
- 会場の信頼性（watch.venues・美術館級）: +10
- 開催期間が近い（30日以内に開始、または開催中で残り7日以上）: +10
- 減点: 絵画/古美術/IP・キャラクター展 -30、物販・イベント中心 -20、プロダクトショールーム型/AI生成画像展 -30、AI言及のみで作家主導/空間性が不明 -15。地域による減点はしない
- 強制: NEORT++/オンチェーン/ジェネラティブ展は常に掲載（最低でも掲載しきい値に引き上げ）。intake投稿は +10（ただし除外条件には勝てない）
- しきい値: 掲載60 / 注目80 / 通知70。日付・会場が公式で未確認のものは掲載せず裏取りキューへ
